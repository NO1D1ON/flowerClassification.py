# flowerClassification.py

Ini merupakan kode pretrained yang ditujukan untuk melakukan klasifikasi pada 5 jenis bunga. Adapun jenis/kelas dalam dataset, yakni:
 - Daisy
 - Dandelion
 - Roses
 - Sunflower
 - Tulip

Kode ini merupakan bagian dari pembelajaran deeplearning dan belum dilakukan optimasi untuk meningkatkan akurasi atau melakukan pruning.
Meskipun demikian, tidak menutup kemungkinan akan dilakukan hal tersebut. 

Sedikit penjelasan kode:
Kode menggunakan beberapa library, diantaranya _pyTorch, Matplotlib, sklearn, dan numpy_.
